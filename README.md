# Hou.la Connect

Hou.la Connect relie ton live [Hou.la](https://hou.la) à ton PC : packs interactifs, overlays,
sons, commandes du chat, Stream Deck.

## Télécharger

La dernière version est toujours ici : **[Releases, dernière version](https://github.com/Hou-la/houla-connect-app/releases/latest)**.

| Système | Fichier |
|---|---|
| Windows | `Houla-Connect-<version>.exe` |
| macOS | `Houla-Connect-<version>.dmg` |
| Linux | `Houla-Connect-<version>.AppImage` |

Une fois installée, l'application se met à jour toute seule.
